# Prompt-інжиніринг — лабораторні роботи

Рудько Юрій, група мКН-24, ТНПУ ім. В. Гнатюка.

Репозиторій містить код лабораторних робіт, самостійної роботи та підсумкового проєкту з дисципліни
«Prompt-інжиніринг» (спеціальність «Комп'ютерні науки»).

## Запуск

Код використовує офіційний Python SDK **google-genai**. Ключ API ніколи не зберігається в коді:

* локально — у файлі `.env` (`GEMINI_API_KEY=...`, файл додано до `.gitignore`);
* у Google Colab — у розділі **Secrets** (`GEMINI_API_KEY` або `GOOGLE_API_KEY`).

```bash
pip install -r requirements.txt
cp .env.example .env   # вставити власний ключ
python lab2/main.py
```
